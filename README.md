# 🎯 発表順ルーレット (Presentation Order Randomizer)

授業における 8 グループの発表順を、かっこいいルーレット演出で公平に決めるシングルファイル Web アプリです。

## 使い方
`index.html` をブラウザで開くだけ（ビルド不要・依存なし）。

- **🎰 スピン** … 残りグループから1つを抽選して発表順を確定
- **リセット** … 最初からやり直し
- **🔊 効果音** … 効果音の ON/OFF

決定した順番は右側のパネルに、メンバー名つきで上から順に表示されます。

## 採用したランダム化手法と根拠

参照記事（臨床試験の無作為化解説、亀田メディカル
[「ランダム化」](https://www.kameda.com/pr/intensive_care_medicine/post_2.html)）で紹介されている
3手法を「発表順決め」の用途に当てはめて検討しました。

| 手法 | 内容 | 発表順への適合性 |
|------|------|------------------|
| 単純ランダム化 | 毎回くじを引き直す | ✗ 重複・抜けが発生しうる |
| 層別ランダム化 | 重症度等の因子で層別 | ✗ 層別する因子がない |
| **ブロックランダム化** | **1巡内で各対象がちょうど1回ずつ・偏りなく割付** | **◎ 最適** |

発表順は「全グループが重複・抜けなく、ちょうど1回ずつ並ぶ」必要があるため、
**ブロックランダム化の考え方（＝一様ランダムな順列）** を採用しました。

### 実装
- 残ったグループから1つずつ均等な確率で抽出（＝Fisher-Yates シャッフルと等価）。
  すべての並び順が等確率になります。
- 乱数源は `crypto.getRandomValues` を**棄却サンプリング**と併用し、
  剰余バイアス（`% n` による偏り）のない一様乱数を実現。

## 技術
- 単一の `index.html`（HTML + CSS + Vanilla JS、Canvas 描画）
- 外部ライブラリ・ネットワーク通信なし
