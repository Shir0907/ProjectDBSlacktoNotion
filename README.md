# 🎯 発表順ルーレット (Presentation Order Randomizer)

授業におけるグループの発表順を、かっこいいルーレット演出で公平に決める Web アプリです。

## ページ構成
| ファイル | 役割 |
|----------|------|
| `index.html` | ルーレット本体（抽選・編集・履歴・結果出力） |
| `guide.html` | ランダムの仕組みを図解した解説書（高校生向け） |
| `style.css` / `app.js` | 共通スタイル / ルーレットのロジック |

## 使い方
`index.html` をブラウザで開くだけ（ビルド不要・依存なし）。ヘッダーから解説書へ移動できます。

### 主な機能
- **🎰 スピン / リセット** … 残りグループから1つを抽選して発表順を確定／最初からやり直し
- **✏️ グループを編集** … グループ数・グループ名・メンバー名を変更（`localStorage` に保存）
- **🔁 前回の1番目を先頭にしない** … 連続して同じ班がトップにならないようにする配慮機能
- **📋 コピー / 🖼 画像保存 / 🖨 印刷** … 決定した発表順を出力
- **📜 抽選の履歴** … 過去の結果を自動記録（最大20件、消去可）
- **🔊 効果音** … 効果音の ON/OFF

決定した順番は右側のパネルに、メンバー名つきで上から順に表示されます。

## 採用したランダム化手法と根拠

参照記事（臨床試験の無作為化解説、亀田メディカル
[「ランダム化」](https://www.kameda.com/pr/intensive_care_medicine/post_2.html)）で紹介されている
3手法を「発表順決め」の用途に当てはめて検討しました。

| 手法 | 内容 | 発表順への適合性 |
|------|------|------------------|
| 単純ランダム化 | 毎回くじを引き直す | ✗ 重複・抜けが発生しうる |
| 層別ランダム化 | 重症度等の因子で層別 | ✗ 層別する因子がない |
| **ブロックランダム化** | **1巡内で各対象がちょうど1回ずつ・偏りなく割付** | **◎ 最適** |

発表順は「全グループが重複・抜けなく、ちょうど1回ずつ並ぶ」必要があるため、
**ブロックランダム化の考え方（＝一様ランダムな順列）** を採用しました。

### 実装
- 残ったグループから1つずつ均等な確率で抽出（＝Fisher-Yates シャッフルと等価）。
  すべての並び順が等確率になります。
- 乱数源は `crypto.getRandomValues` を**棄却サンプリング**と併用し、
  剰余バイアス（`% n` による偏り）のない一様乱数を実現。

> 連続回避機能をオンにすると前回トップの班だけ1番目の抽選から外れるため、純粋な等確率はわずかにくずれます（目的に応じて ON/OFF）。詳しくは `guide.html` の解説を参照。

## 技術
- 静的な HTML + CSS + Vanilla JS（Canvas 描画）。ビルド不要、外部ライブラリなし
- 設定・履歴は `localStorage` に保存
